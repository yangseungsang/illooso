# 일로오소 · ILLOOSO

목적지 근처에서 운전자와 동승자가 만나기 좋은 승하차 장소를 찾는 웹 프로토타입입니다. 장소 선택부터 모의 내비게이션 안내, 만남 링크 공유, 이용 경험 제보까지 직접 체험할 수 있습니다.

기획서: [Notion 원문](https://app.notion.com/p/41388b2f14b180818a8ec3bc0078d4f0)

## 실행

Node.js와 npm이 설치된 환경에서 실행합니다. API 키나 별도 서버 설정은 필요하지 않습니다.

```bash
cd "/Users/yangseungmin/Documents/ChatGPT/현차앱 2/illooso"
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다. 포트가 사용 중이면 터미널에 표시된 주소를 확인하세요.

```bash
npm run build
npm test
npm run typecheck
```

- `build`: Next.js 정적 내보내기를 수행하며 배포 파일은 `out/`에 생성됩니다.
- `test`: 추천 조건, 운영 시간 경계, 공유 데이터 검증 등 도메인 로직 테스트를 실행합니다.
- `typecheck`: TypeScript 타입을 검사합니다.
- `npm start`는 현재 개발 서버를 실행합니다. 운영 배포에는 `out/`을 정적 호스팅하세요.

## 핵심 경험과 구체화한 설계

운전자는 내비게이션에서 가져온 것으로 가정한 목적지를 확인하고 **바로 태우기 / 기다렸다 태우기 / 주차장 찾기** 중 상황을 선택합니다. 방문 시간과 도보 거리를 설정하면 지도와 목록에서 같은 후보를 비교할 수 있습니다. 동승자는 별도 앱 설치 없이 공유받은 링크로 만남 장소를 확인합니다.

- 미확인·정차 금지 구간을 추천에서 먼저 제외하고, 이용 시간과 대기 가능 조건을 적용합니다. 가까운 거리나 이용자 제보 수가 이러한 조건을 뒤집지 않습니다.
- 후보 상세에 도보 거리, 차량 우회 거리, 접근 방향, 운영 시간, 예시 요금과 추천 이유를 함께 제공합니다.
- 목적지를 바꾸면 도보 거리와 추천 순서를 다시 계산합니다. 조건 변경 시 기존 장소 선택과 모의 안내를 초기화합니다.
- 저장한 장소, 이용자 제보 필터, 내 제보 수정·철회로 탐색 이후의 흐름을 보완했습니다. 새 제보는 `확인 중`이며 정차 허용 조건을 바꾸지 않습니다.
- 로딩, 검색 결과 없음, 연결 실패와 재시도, 링크 만료·취소·오류 상태를 제공합니다.
- 주행 상태를 켜면 검색·장소 변경·제보 입력 등 주요 조작을 제한합니다. 모바일에서는 화면 배치를 조정하고, 모달은 Escape 닫기와 키보드 포커스 이동을 지원합니다.

## 체험 및 확인 순서

1. 목적지 카드를 눌러 평거동의 샘플 목적지 3개 중 하나를 선택합니다. 장소 검색, 방문 시간, 최대 도보 거리, 정렬을 바꾸며 결과를 확인합니다.
2. `기다렸다 태우기`와 `주차장 찾기`에서 대기·주차 가능한 후보만 남는지 확인합니다. 검색 결과가 없으면 `장소 다시 찾기`로 복구합니다.
3. 지도 마커 또는 목록에서 후보를 선택합니다. 저장 버튼을 누르고 `저장한 장소`와 새로고침 후 유지 여부를 확인합니다.
4. 상세에서 `이곳으로 안내` → 연결 중 → 안내 중 → 지도 위 `도착 체험`을 순서대로 실행합니다.
5. 상단 `Pleos Connect` 설정에서 `연결 실패 체험`을 켠 뒤 다시 안내를 요청하고, 오류 화면의 `다시 연결하기`를 확인합니다.
6. 도착 전 상세의 `동승자에게 공유`에서 메모를 입력하고 링크·QR·`동승자 화면 보기`를 확인합니다. 목적지를 변경한 뒤 공유해도 승객 화면의 목적지와 도보 거리가 일치하는지, 새 시크릿 창에서도 링크를 열 수 있는지 확인합니다.
7. 도착 후 `이용 경험 남기기`로 실제 이용 일시와 경험을 등록합니다. `내 제보`에서 수정·철회를 확인합니다. 미래의 이용 일시는 제출할 수 없습니다.
8. 설정에서 `주행 중 모드`를 켜고 입력 제한을 확인한 뒤 배너의 `주차 상태로 전환`으로 복구합니다.

기본 방문 시간은 14시이며 샘플 데이터의 기준일은 2026년 11월 13일입니다. 브라우저 시간에 따라 공유 링크의 만료와 제보의 미래 날짜 검증이 적용됩니다.

## 데이터와 연동 범위

**실제 차량·지도·법규 API에는 연결하지 않습니다.** Pleos 연결, 차량 위치, 경로, ETA, 도보·우회 거리는 시뮬레이션입니다. 평거동을 배경으로 하지만 시설 이름, 도로 배치, 좌표, 운영 시간, 요금, 제보와 확인 상태는 예시입니다. SVG 지도와 `조건 확인 완료` 표시는 실제 정차 허용이나 현장 안전을 보증하지 않습니다.

저장한 장소, 제보, 부정확한 제보 신고, 공유 상태는 같은 브라우저의 `localStorage`에 보관합니다. 로그인이나 기기 간 동기화는 없습니다. 저장소 사용이 차단되면 일부 변경은 현재 화면에서만 유지되며, 브라우저 데이터 삭제 시 기록이 사라집니다. 검색 조건과 모의 안내 상태는 새로고침 시 기본값으로 돌아갑니다.

공유 링크는 선택한 장소·목적지·메모를 URL에 담은 **2시간 유효 스냅샷**입니다. 다른 브라우저에서도 정보를 읽을 수 있지만 실시간 차량 추적이나 서버 동기화는 제공하지 않습니다. 같은 브라우저에서는 저장된 변경·취소 상태를 반영하고, 이미 전달한 링크는 다른 기기에서 갱신·취소되지 않습니다. 내용 변경 시 새 링크를 전달해야 합니다. URL 데이터는 암호화되지 않으므로 민감한 정보를 메모에 넣지 마세요.

휴대폰으로 QR을 열려면 휴대폰에서도 접속 가능한 배포 주소 또는 개발 컴퓨터의 네트워크 주소에서 공유 링크를 만들어야 합니다. 휴대폰의 `localhost`는 개발 컴퓨터를 가리키지 않습니다.

## 코드 구조와 확장 지점

```text
app/
  page.tsx              화면, 로컬 상태, 안내·공유·제보 사용자 흐름
  layout.tsx            문서 메타데이터와 공통 레이아웃
  globals.css           디자인 토큰, 컴포넌트 스타일, 반응형 레이아웃
components/
  PickupMap.tsx         조작 가능한 SVG 데모 지도
  pickup-map.css        지도·마커·경로 스타일
  Modal.tsx             재사용 모달과 키보드 접근성
lib/
  domain.ts             데이터 모델, 샘플 데이터, 추천·공유·저장 함수
tests/
  domain.test.ts        도메인 경계 조건 테스트
next.config.ts          정적 내보내기 설정
```

Next.js App Router, React, TypeScript, Tailwind CSS 4와 CSS를 사용하며 아이콘은 Lucide, QR은 `qrcode.react`로 구성했습니다.

실제 서비스로 확장할 때는 `lib/domain.ts`의 샘플 데이터와 추천 입력을 검증된 도로·시설 데이터 공급자로 교체하고, `startRoute`의 타이머를 Pleos 어댑터로 연결할 수 있습니다. SVG 지도는 지도 SDK와 차량·보행 경로 서비스로 대체해야 합니다. 공유는 서버 발급 토큰, 서버 기준 만료·취소, 위치 갱신을 갖춘 세션 API로, 저장·제보는 사용자 인증과 검토 이력이 있는 API로 옮기는 것이 다음 단계입니다. 이 연동들은 현재 구현 범위에 포함되지 않습니다.
