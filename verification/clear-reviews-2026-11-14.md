# 후기 화면 간소화 검증 · 2026-11-14

대상: `1.7.0-clear-reviews`, versionCode 8. Pleos 2.1.0 AVD `emulator-5554`, 사용자 10, 주차 상태에서 확인했습니다.

## 화면 변경

- `방문 후기 / 이용 정보`, `내 상황 / 전체`, 별도 전체 정렬 버튼을 `내 상황 우선 / 전체 · 최신순 / 전체 · 도움순` 메뉴 하나로 정리했습니다.
- 이미 보이는 목록으로 이동하던 `후기 N개 읽기` 버튼을 없앴습니다.
- 장점과 주의점은 한 줄씩 강조하고, 각 항목의 근거 건수와 요약 대상 건수를 유지했습니다. 예시 포함 표시는 실제 요약에 예시 후기가 포함될 때만 표시합니다.
- 개별 후기의 배경 박스를 제거하고 얇은 구분선을 사용했습니다. 작성자·방문 시각은 작게, 본문은 24sp로 표시합니다. 긴 후기의 더 읽기는 필요한 경우만 나타납니다.
- 장소의 `⋯` 메뉴로 이용 정보·저장·후기 남기기를 모았습니다. 이용 정보는 별도 팝업에서 열리며 저장은 읽던 후기의 스크롤 위치를 바꾸지 않습니다.
- 장소명·차량/도보 정보와 하단 선택 버튼은 고정하고 가운데 본문만 스크롤합니다. 기본 추천과 새로 선택한 장소는 후기 카드가 바로 열립니다.

## 빌드 및 코드 검토

JDK 17, `:app:assembleDebug :app:testDebugUnitTest` 성공. JUnit 32개 통과, 실패·오류 0개입니다. 장소 15개, 선택 4개, 후기 8개, 좌표 투영 5개입니다. 이번 UI 변경을 그대로 반복하는 새 단위 테스트는 추가하지 않았습니다.

별도 코드 검토에서 후기 기준 선택과 요약·정렬 매핑, 새 콜백의 차량 조작 제한 검사, 이용 정보 팝업의 독립적인 본문, 저장 시 스크롤 유지, 새 아이콘 상태 처리를 확인했습니다.

## 실제 AVD 화면에서 확인

1. 설치 후 기본 장소가 `내 상황 우선`으로 열렸습니다. 유사 방문 3건의 요약과 후기 본문 2건이 첫 화면에 함께 보였습니다.
2. 기준 메뉴에서 `전체 · 최신 방문순`을 선택했습니다. 전체 18건 요약과 최신 방문 목록으로 바뀌었습니다.
3. `전체 · 도움이 많은 순`을 선택했습니다. 전체 요약은 유지되고 첫 두 후기의 도움 수가 29, 26으로 표시됐습니다.
4. `⋯ → 이용 정보`에서 진입 방향·이용 시간·요금·추가 이동 정보를 읽고 닫았습니다. 기존 후기 화면이 유지됐습니다.
5. 후기 본문을 드래그해 끝까지 이동했습니다. 장소명·차량/도보·하단 선택 버튼은 고정됐습니다.
6. 스크롤한 위치에서 장소를 저장했습니다. 읽던 위치가 유지되고 메뉴가 `저장 취소`로 바뀌었습니다. 검증 후 저장을 취소해 기존 상태로 돌렸습니다.
7. `지도 보기`로 접었을 때 실제 지도와 도로 색상이 표시됐습니다. 지도에서 주차 마커를 누르자 신평공원길39번길 예시 주차 공간의 후기 카드가 바로 열렸습니다.
8. 해당 장소의 `전체 · 최신순` 화면에서 전체 36건 요약, 장점·주의점, 후기 2건이 첫 화면에 보이는 상태를 저장했습니다. [최종 실행 화면](pleos-clear-reviews-2026-11-14.png).
