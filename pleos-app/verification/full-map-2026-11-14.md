# 하단 안내 제거·상단 필터 검증 · 1.12.0-full-map

## 변경

- 일반 지도 탐색에서 `지도에서 만날 곳을 선택하세요` 안내, 후보 개수, 하단 필터로 구성된 바를 제거했다.
- 방문 시간·목적지까지 최대 직선 거리 필터 버튼을 상단 목적지 검색 오른쪽의 64dp 터치 영역으로 옮겼다. 기존 필터 대화상자에 연결한다.
- 안내 카드가 없는 지도 하단 여백을 0으로 처리해 출처 표시 바로 위까지 지도를 그린다. 메뉴·목록 패널의 하단 여백은 24dp로 별도 유지한다.
- 후보가 없는 상태와 진행 중 안내 상태에 필요한 카드는 유지한다. 목적지·후기 패널은 하단 카드가 없어도 열 수 있도록 null 참조를 처리했다.
- 용도 버튼과 지도 카메라 코드는 변경하지 않았다. 1.11에서 적용한 시점 유지·라벨·추천 표시를 유지한다.

## 검증

- 최종 `:app:assembleDebug :app:testDebugUnitTest` 성공. 기존 JUnit 50개 통과, 실패·오류 0개. 이번 단순 배치 변경에 별도 단위 테스트를 추가하지 않았다.
- Pleos 2.1.0 AVD `emulator-5554`, user 10에 설치·실행. versionCode 13 / versionName `1.12.0-full-map` 확인.
- 실제 화면에서 상단 목적지 검색 오른쪽의 필터 아이콘, 사라진 하단 안내, 출처 표시 위까지 확장된 지도와 후보 라벨을 확인했다. 당시 기기에 저장된 목적지는 평거로 북측 예시 주차 공간이었다.
- 상단 필터 클릭을 시도하던 중 사용자가 앱을 조작해 컴퓨터 사용 도구가 동작을 중단했다. 최신 화면을 다시 확인한 뒤 추가 입력 없이 점검을 종료했다. 따라서 이번 기기 점검에서 필터 대화상자 열기·적용까지 통과했다고 주장하지 않는다. 새 버튼은 기존 `showFilters()`에 연결되며 코드를 검토했다.
- `summary`가 없는 목적지·후기 패널, 지도 여백, 메뉴·목록 여백의 참조를 별도 읽기 검토했다. 모든 필터·빈 상태·안내 조합을 기기에서 재시험하지 않았다.
- 전달 APK는 최종 빌드와 바이트 일치하며 SHA-256은 `apk-sha256.txt`에 기록한다. 이전 화면 캡처는 해당 버전의 기록이며 이번 버전의 별도 PNG는 저장하지 않았다.
