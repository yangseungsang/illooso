# 지도 라벨·시점 유지 검증 · 1.11.0-map-labels

## 구현

- 지도 후보에 짧은 장소명, 현재 목적지까지 실제 좌표로 계산한 직선 거리, 주차/승하차 예시를 표시한다. 전체 장소명은 후기 카드에 유지한다.
- 현재 용도·시간·거리·검색 조건을 만족하는 후보 중 직선 거리가 가장 가까운 한 곳에 파란 테두리·별표·`가까운 추천`을 표시한다. 추천과 사용자 선택은 별개다. 후기 점수나 실시간 정차 가능성을 새로 추정하지 않는다.
- 라벨은 핀·목적지·지도 버튼·다른 라벨과 겹치지 않는 가까운 빈 공간에 배치하고, 실제 지점과 연결선을 그린다. 라벨 전체를 눌러 해당 후기를 연다. 공간이 부족하면 핀을 남기며, 극도로 작은 지도 영역에서는 라벨 배치를 건너뛴다.
- 용도 버튼은 기존 뷰에서 선택 색상, 후보, 추천, 하단 개수만 갱신한다. 화면 전체 재생성과 자동 `recenter()`를 제거했다.
- 후보·목적지 메타데이터·오버레이 높이 변경은 지도 시점을 바꾸지 않는다. 지도 투영의 세로 기준점도 오버레이 여백과 분리했다. 초기 배치, 명시적 목적지 변경, 전체 보기 버튼은 지도를 맞춘다. 사용자의 확대·축소·드래그는 그대로 작동한다.

## 기기 확인

Pleos 2.1.0 AVD `emulator-5554`, user 10, 주차 상태, 중앙 앱 패널 약 840px. 저장된 목적지는 신세계수영장, 기본 거리 조건은 직선 500m다.

1. 시작 화면의 후보 4곳에 장소명과 거리가 모두 표시됨: 평거로 북측 169m, 평거로36번길 235m, 신평공원길39번길 281m, 신평공원길47번길 313m. 첫 후보만 가까운 추천으로 강조되고 후기는 자동으로 열리지 않음.
2. 바로 태우기→기다리기 전환 시 후보가 4곳→2곳으로 바뀌고, 도로·목적지·남은 핀의 화면 위치와 배율은 유지됨.
3. 최종 APK에서 신평공원길39번길 이름 라벨을 누르자 해당 장소의 후기 36건과 직선 281m가 표시됨. 지도 보기로 닫은 뒤 원래 지도 시점이 유지됨.
4. 축소 버튼을 한 번 누르고 지도를 오른쪽·위로 드래그한 뒤 주차장을 선택함. 후보와 라벨만 2곳으로 바뀌며 목적지·추천 핀·주차 핀·배경 도로 위치와 배율은 그대로 유지됨.
5. 다시 바로 태우기로 바꾸면 동일한 지도 시점에 4곳이 복원됨. 라벨이 목적지·조작부·서로를 가리지 않는 것을 확인함.

최종 화면은 사용자가 조절한 시점에서 용도를 다시 전환한 결과이며, 기본 최초 배율 화면은 아니다. Android Studio Take Screenshot으로 저장했다.
