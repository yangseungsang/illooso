# 후기 중심 상세 검증 · 2026-11-14

대상: Pleos Connect 네이티브 앱 `1.4.0-reviews` (`versionCode 5`). 실제 Pleos 2.1.0 AVD `emulator-5554`, 사용자 10, 주차 상태에서 확인했다.

## 구현

- `상세`의 첫 화면은 `장소 후기`다. `내 상황 / 전체` 전환과 장점·살펴볼 점의 대표 항목, 근거 건수를 제공한다.
- `내 상황`은 한국 시간의 예상 도착 시각(현재 시각 + 해당 장소의 차량 이동 시간), 같은 평일/주말 구분, 시각 전후 2시간, 같은 방문 목적을 기준으로 한다. 직접 설정한 방문 시간이 있으면 해당 시각을 사용하고 `설정 시간`으로 표시한다.
- 일치한 후기만 개인화 요약에 사용한다. 일치하지 않는 후기는 목록의 `다른 상황의 후기`에 구분하며, 일치한 후기가 없으면 빈 상태와 전체 후기 전환을 제공한다.
- `전체`는 전체 유효 후기의 요약을 제공한다. 최신순은 방문 시각 기준, 도움순은 도움 수와 방문 시각 기준이다. 미래 방문·미래 작성 기록은 제외한다.
- 예시 후기 138건은 6개 장소의 고정된 방문 시간대와 과거 평일·주말을 사용한다. 조회 조건에 맞춰 후기의 방문 시각을 생성하지 않는다. 예시 후기·예시 도움 수와 기기 내 기록을 구분해 표시한다.
- 요약은 후기 태그 집계다. 외부 AI 호출이나 실시간 교통 분석을 사용하지 않는다. 내 기록은 `확인 중`이며 도로의 정차 허용 조건을 바꾸지 않는다.
- 새 후기에는 방문 목적을 저장한다. 기존 저장 데이터에서 목적이 없는 경우 추정하지 않고 유사 상황 요약에서 제외한다. 미래 방문 시각의 저장을 거절한다.
- 기본 장소 추천도 장소별 예상 도착 시각에 운영 중인지 판정한다. 방문 시간을 직접 지정한 기존 필터는 지정 시간을 사용한다.

## 화면 검증

실제 AVD의 약 841dp 폭 앱 영역에서 다음을 확인했다.

- `내 상황`에 도착 예상 시각, 평일/주말, 방문 목적, 근거 건수와 요약이 표시된다.
- `전체`로 전환하면 전체 후기 요약과 최신순 선택이 표시된다.
- `도움이 많은 순` 선택 시 첫 후기와 정렬 표시가 바뀐다. 정렬 선택창의 글자 잘림을 발견해 행 높이를 72dp로 수정한 뒤 최종 APK에서 다시 확인했다.
- `후기 N개 읽기`가 패널 본문을 후기 목록으로 이동시킨다. 패널 내부 스크롤 중 지도와 하단 장소명·차량 이동 시간·도보 거리·주요 버튼은 유지된다.
- `이용 정보`로 같은 패널에서 진입 방향·이용 시간·요금·저장을 확인하고 후기로 돌아올 수 있다.
- 후기 작성창에 유형, 방문 목적, 날짜·시각 변경, 추가 설명과 로컬 저장 안내가 표시된다. 검증용 기록을 남기지 않고 취소했다.
- 최종 화면을 `내 상황` 요약으로 복귀시켰다.

[실행 화면](pleos-context-reviews-2026-11-14.png)은 같은 후기 레이아웃의 AVD 캡처다. 시간 경과에 따라 표시되는 예상 도착 시각과 유사 후기 수는 달라질 수 있다. 앱은 장치 시스템 시각을 `Asia/Seoul`로 변환한다. 이 AVD의 순정 상단 시계 표시와 장치 시스템 시각은 일치하지 않아 상단 시계 텍스트를 기준으로 사용하지 않았다.

## 이번 검증의 한계

- 새 후기의 저장·수정·삭제를 실제 AVD에서 끝까지 수행하는 영속성 검증은 이번에 하지 않았다. 작성창과 기존 로컬 저장 연결은 유지되며 도메인 정렬·집계는 단위 테스트로 확인했다.
- 주행 중 정책 전환, QR 공유, 실제 SDK 경로 안내 성공은 이번 변경의 수동 검증 대상이 아니다. 기존 차량 UX 제한 검사는 유지했다.
- 앱 지도는 예시 도식이다. 별도 순정 내비게이션의 도로 배경 공백은 여전히 미해결이며, 이번 후기 기능으로 복구됐다고 볼 수 없다.
- 실차 사용 적합성이나 실제 도로 정보의 정확성을 검증한 결과는 아니다.
