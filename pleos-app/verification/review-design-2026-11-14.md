# 후기 화면 디자인 검증 · 1.9.0-review-design

사용자가 제공한 `신평공원길 주차 후기 화면.png`의 시각적 위계를 실제 Android Views 화면에 반영했다. 결과는 이미지 목업이 아닌 동작하는 Pleos 앱이다.

## 변경

- 굵은 장소명, 위치 아이콘 타일, 차량 시간 배지, 아이콘을 포함한 지도 버튼.
- 방문 후기 수를 파랑으로 강조하고 정렬 선택은 하나로 유지.
- 장점과 주의를 민트·살구 배경, 아이콘·텍스트·언급 수로 구분. 예시 포함 표시 유지.
- 작성자 아바타, 굵은 작성자명, 방문 날짜, 본문, 이용 목적·예시 후기 배지로 후기의 읽는 순서 정리.
- 도움 버튼의 기기 내 선택·취소와 숫자·선택 상태 갱신. 재평가 시 도움순 정렬에 반영하며 누를 때 읽던 위치는 유지.
- 저장·내비 안내·공유 버튼을 하단에 고정. 장소명·이동 정보는 상단에 고정하고 후기 영역만 스크롤.
- 거리는 실제 계산한 **직선 거리**를 유지한다. 참고 이미지의 도보 시간이나 보행 경로를 새로 추정하지 않았다.

## 실행 확인

Pleos 2.1.0 AVD `emulator-5554`, user 10, 주차 상태, 중앙 앱 패널 폭 약 840px에서 확인했다.

1. 긴 `신평공원길39번길 예시 주차 공간` 제목과 지도 버튼이 겹치지 않고 표시됐다.
2. 내 상황 우선에서 전체 최신순으로 바꾸자 전체 36건 요약과 장점 18건·주의 8건, 최신 방문 후기 목록으로 바뀌었다.
3. 첫 후기의 도움 29 → 선택 시 30, 화면을 닫고 다시 열어도 30과 선택 색상 유지, 재선택 시 29로 복귀했다. 중복 가산 없이 선택·취소됐다.
4. 하단 저장 버튼이 빈 아이콘 → 채운 아이콘으로 바뀌고 재진입 후 유지됐다. 취소하면 빈 아이콘으로 복귀했다. 테스트로 추가한 도움·저장 선택은 모두 취소했다.
5. 후기 본문을 아래로 스와이프해 과거 후기들을 읽는 동안 장소명·이동 정보·저장·안내·공유 버튼이 고정됐다.
6. 지도 보기로 닫고 지도에서 다른 장소를 선택해 새 후기 화면으로 진입했다. 선택한 장소와 거리 표시가 함께 변경됐다.

## 빌드

- `:app:assembleDebug :app:testDebugUnitTest` 성공. 기존 도메인 단위 테스트 42개 통과, 실패·오류 0개.
- versionCode 10 / versionName `1.9.0-review-design` 설치 확인.
- 배포 APK `artifacts/illooso-pleos-debug.apk`는 최종 빌드 출력과 바이트가 일치한다. 해시는 `verification/apk-sha256.txt`에 기록했다.
- 새 UI에서 실제 내비 경로를 다시 요청하지는 않았다. 내비 전달 로직은 변경하지 않았으며 이전 1.8 검증은 `destinations-2026-11-14.md`에 있다.
- 600dp 미만 패널의 모든 글꼴 확대 조합과 실제 차량 주행은 이번에 시험하지 않았다. 후기·차량 예상 시간·정차 조건은 기존의 명시된 예시 데이터이며 도움 반응은 서버 투표가 아닌 기기 내 상태다.
