# 일로오소 · Pleos 네이티브 앱

**이 디렉터리가 주 실행 프로젝트입니다.** Pleos Connect / Android Automotive용 Java 앱으로, Android Views와 Canvas에서 실제 OpenStreetMap 타일 및 도로 오버레이를 렌더링합니다. WebView를 사용하지 않으며, 내비게이션 연결은 실제 `NaviHelper` SDK를 통해 이루어집니다. 별도 `../illooso/`는 초기 웹 프로토타입과 동승자 공유 화면입니다.

기획서: [Notion 원문](https://app.notion.com/p/41388b2f14b180818a8ec3bc0078d4f0)

## 장소 유형 아이콘 · 1.15.0-place-icons

최신 버전은 **1.15.0-place-icons / versionCode 16**입니다. 일반 승하차 지점의 숫자 마커를 **차량 모양 승하차 아이콘**으로 바꿨습니다. 추천 장소는 **★**, 추천으로 강조되지 않은 일반 주차장은 **P**로 표시합니다. 숫자를 추천 순위로 오해하지 않고 장소 유형을 구분할 수 있도록 정리했습니다.

장소명·직선 거리 라벨, 터치 범위, 추천 계산과 지도 위치·확대 수준 유지 방식은 그대로입니다. 승하차 아이콘은 일반 상태에서 초록색, 선택 상태에서 흰색으로 표시하고 접근성 설명에도 승하차 지점임을 명시합니다. 빌드·기기 확인 범위는 [검증 기록](verification/place-icons-2026-11-14.md), 화면은 [장소 유형 마커](verification/pleos-place-icons-2026-11-14.png)를 참고하세요.

빌드와 기존 JUnit 50개가 통과했고 Pleos에 설치했습니다. 기다리기와 바로 태우기 전환 후 일반 승하차 아이콘·추천 별표·주차장 P 및 지도 위치 유지를 화면에서 확인했습니다.

## 지도에서 바로 비교하기 · 1.11 구현 유지

**1.11.0-map-labels / versionCode 12**에서 적용한 지도 비교 기능을 유지합니다. 지도 후보에는 누르기 전부터 짧은 장소명·목적지까지의 직선 거리·주차 또는 승하차 예시가 표시됩니다. 현재 용도·시간·거리 조건을 만족하는 후보 중 목적지와 직선 거리가 가장 가까운 곳을 **★ 가까운 추천**과 파란 카드로 강조합니다. 후기 점수나 AI 분석에 따른 순위가 아니며, 실제 정차 허용 여부를 보증하지 않습니다.

상단 **바로 태우기·기다리기·주차장** 버튼은 기존 화면에서 선택 상태와 지도 위 후보·추천만 갱신합니다. 지도의 위치·확대 수준을 유지하며 용도에 맞춘 자동 이동을 하지 않습니다. 첫 화면과 목적지 변경, 사용자가 직접 누르는 전체 보기 버튼은 지도 범위를 맞춥니다. `MapLabelLayout`은 핀·목적지·지도 조작부·다른 라벨을 피해 이름표를 배치하며, 겹침 없이 놓을 공간이 없으면 핀을 유지합니다. 라벨 전체가 장소 정보와 후기를 여는 터치 영역입니다.

최종 1.11 빌드와 JUnit **50개**가 통과했고 Pleos 에뮬레이터에 설치했습니다. ## 지도에서 먼저 찾기 · 1.10 구현 유지

**1.10.0-map-browse / versionCode 11**에서 적용한 지도 우선 탐색을 유지합니다. 앱을 새로 열거나 목적지를 바꾸면 주변 후보를 지도에 표시하며, 첫 장소나 후기를 자동으로 열지 않습니다. 상단의 **바로 태우기·기다리기·주차장** 버튼을 바로 눌러 지도 후보를 바꿀 수 있습니다. 지도 지점이나 라벨을 선택하면 기존 장소 정보·후기 카드가 열립니다.

`지도 보기`로 돌아가면 일반 선택을 해제하고 지도를 넓게 표시합니다. 1.10에서 사용하던 작은 안내와 후보 수 바는 1.12에서 제거했습니다. 진행 중인 안내 대상은 용도 변경이나 지도 복귀 시 보존합니다. 방문 시간·직선 거리 조건으로 후보를 좁힐 수 있으며 검색 조건에 맞는 장소가 없으면 빈 상태를 표시합니다. 실제 OSM 지도와 도로 평가 예시, 후기의 요약·정렬·도움·저장, 순정 내비 전달을 유지합니다.

1.10 빌드와 JUnit **45개**가 통과했고 Pleos AVD에 설치했습니다. 신세계수영장 기준으로 바로 태우기 4곳, 기다리기 2곳, 주차장 2곳이 지도에 표시되고 p2 지점 선택 시 해당 후기 카드가 열리는 것을 확인했습니다. 이 후보 수는 확인 당시 방문 시간·거리 조건의 결과입니다. [검증 기록](verification/map-browse-2026-11-14.md) · [지도 화면](verification/pleos-map-browse-2026-11-14.png)

## 목적지 검색과 순정 내비 전달 · 1.8.0-destinations 구현 유지

앱 상단의 목적지를 눌러 직접 장소명·주소를 검색하거나 `순정 내비 목적지 가져오기`로 설정된 목적지를 읽습니다. 그 목적지 주변의 정차지를 선택하고 후기를 확인한 뒤 `이곳으로 내비 안내`를 누릅니다. 순정 내비에 보내는 좌표는 **최종 방문 시설이 아닌 선택한 승하차·주차 지점**입니다.

직접 검색은 평거동 주변의 실제 OSM 노드 8개를 담은 로컬 카탈로그입니다. 평거동 행정복지센터·어린이전문도서관·진양호지구대·신세계수영장·청춘극장·스타벅스·다이소·올리브영을 검색할 수 있습니다. 전국 주소 검색이나 현재 영업 여부 확인 기능은 아닙니다. 목적지 위치는 지도 등록점이며 현장 출입구를 조사한 자료가 아닙니다.

초기 목적지는 OSM node `2691429153`인 평거동 행정복지센터(`35.1738345, 128.0653891`)입니다. 추천은 이 시설에서 반경 1.5km 범위의 목적지를 지원합니다. 범위 밖의 내비 목적지는 좌표를 유지하되 정차지 정보가 없는 지역임을 표시합니다. 목적지가 바뀌면 해당 좌표로 후보와 거리를 다시 계산합니다. 표시와 필터의 **직선 거리**는 실제 좌표의 대권거리이며 보행 경로 거리가 아닙니다. 차량 시간과 정차 조건은 계속 예시입니다.

장소·이동 정보 → 장점·주의 요약 → 후기를 읽고 같은 카드에서 결정합니다. `내 상황 우선 / 전체 · 최신순 / 전체 · 도움순`은 메뉴 하나로 고릅니다. 상단 장소 정보와 하단 내비 안내 버튼은 고정하고 본문만 스크롤합니다. 상단 `후기 남기기`, 본문의 `이용 정보 보기`, 하단 저장 버튼과 `지도 보기`를 사용합니다.

1.8 APK 빌드와 JUnit **42개**가 통과했습니다. 해당 버전의 실제 Pleos AVD에서 `수영장` → 신세계수영장 → p4 직선 169m, `극장` → 청춘극장 → p1 직선 374m 추천과 입력 글자 가독성을 확인했습니다. 순정 내비의 새 빈 목적지 안내와 설정된 p4 목적지 가져오기도 확인했습니다. 1.8 APK에서는 기존 p1 안내 중 p4로 변경한 뒤 앱의 `순정 내비에서 안내 중`·`순정 내비 보기` 표시와 순정 p4 길 안내를 확인했습니다. ## 지도 표시와 데이터 출처

앱 내부 지도는 OpenStreetMap의 실제 도로·건물·지명 타일입니다. 실제 도로 중심선 100개 위에 **추천 25개·주의 21개·제외 11개·미평가 43개** 색상을 겹칩니다. 중심선은 OSM 자료이고 색상은 별도로 부여한 **승하차 평가 예시**입니다. 실제 정차 허용 여부나 실시간 교통 혼잡을 뜻하지 않습니다. [지도 실행 화면](verification/pleos-real-map-2026-11-14.png)

- 실제 지도 배경은 `https://tile.openstreetmap.org/{z}/{x}/{y}.png`의 래스터 타일입니다. 화면에 보이는 타일만 두 작업 스레드에서 요청하며, 앱 고유 User-Agent를 사용합니다. 지역 사전 다운로드나 주변 타일 미리 받기는 하지 않습니다.
- 타일에는 7일 캐시 수명을 적용하고, 만료 후 ETag·Last-Modified가 있으면 조건부 재검증합니다. 메모리와 앱 캐시 디렉터리를 사용하므로 Android가 캐시를 회수하면 다시 요청할 수 있습니다. 연결 실패·로딩 표시와 수동 재시도를 구현했습니다. 장기 장애·캐시 만료 조건을 모두 기기에서 검증했다는 의미는 아닙니다.
- `+ / −`, 드래그, 핀치 확대·축소, 현재 목적지와 정차지 전체 보기, `도로` 색상 켜기·끄기를 구현했습니다. 조작은 기존 차량 UX 제한을 따릅니다.
- OSM 도로 데이터는 2026-11-13 Overpass 응답에서 센터 주변 약 700m 경계와 교차하는 자동차 도로 100개를 추출했습니다. 기존 80개에 북측 도로 20개를 추가했으며 원래 형상과 순서를 보존합니다. `app/src/main/assets/pyeonggeo-roads.json`에 원본 경도·위도 좌표열, OSM ID, 도로명과 출처를 보관합니다. 모든 도로를 평가하거나 현장 조사한 데이터가 아닙니다.
- 색상은 초록 `추천 예시`, 주황 `주의 예시`, 빨강 `제외 예시`, 회색 `미평가`입니다. `RoadOverlayData`에서 실제 형상과 예시 평가를 분리합니다. 도로 색상을 켜고 끄더라도 지도 배경과 장소 선택은 유지됩니다.
- 지도 아래 고정된 `© OpenStreetMap contributors` 표시는 장소 카드에 가려지지 않습니다. 자료는 [OSM 저작권·ODbL 안내](https://www.openstreetmap.org/copyright), 타일 사용은 [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/)을 따릅니다.

앱은 실제 차량·보행 경로를 계산하거나 경로선을 그리지 않습니다. 안내 미리보기는 만남 흐름을 체험하는 로컬 상태이며, 실제 길 안내는 순정 내비게이션에서 확인해야 합니다. 앱 내부 OSM 지도가 표시되는 것과 별도 순정 내비의 배경 공백 해결은 구분합니다.

## 후기의 기준과 요약

- 기본 도착 기준은 `Asia/Seoul`의 현재 시각에 선택 장소의 차량 이동 시간을 더한 값입니다. 방문 시간을 직접 설정하면 그 시각을 사용합니다. 기본 추천 후보도 각 장소의 예상 도착 시각에 운영 중인지 검사합니다.
- `내 상황 우선`은 **같은 평일/주말 구분, 도착 시각 전후 2시간, 같은 방문 목적**을 모두 만족하는 후기를 먼저 보여줍니다. 자정을 넘는 시간 차이는 시계 기준으로 계산합니다. 나머지는 `다른 상황의 후기`로 구분합니다.
- 개인화 요약에는 일치한 후기만 사용합니다. 해당 후기가 없으면 `비슷한 방문 후기가 없어요`를 알리고 아래에 다른 상황의 후기를 보여줍니다. 후기 기준 메뉴에서 전체로 전환할 수 있으며, 일반적인 내용을 대신 개인화된 결론처럼 제시하지 않습니다.
- `전체 · 최신순 / 전체 · 도움순`은 선택 장소의 모든 유효한 후기를 집계합니다. `최신순`은 작성 시각이 아닌 **방문 시각** 기준이며, `도움순`은 도움 수와 방문 시각으로 정렬합니다. 미래 방문·미래 작성 기록은 제외합니다.
- 장점·주의할 점은 후기의 태그를 집계한 결과입니다. 같은 후기에 중복된 태그가 있어도 한 건으로 세며, 대표 항목의 근거 건수를 표시합니다. 외부 AI API나 실시간 교통 정보를 사용하지 않습니다.
- 6개 장소의 예시 후기 138건은 조회 조건과 독립된 고정 방문 시간대·과거 평일/주말로 구성됩니다. 예시 도움 수 역시 샘플 값입니다. 내 기록은 별도로 표시하고 새 제보에는 방문 목적을 저장합니다. 예전 기록에 목적이 없으면 추정하지 않으며, 유사 상황 요약에서 제외하고 전체 목록에는 유지합니다.

후기는 과거 방문자의 경험을 비교하기 위한 정보입니다. 현재 도로 상태나 정차 허용 여부는 현장 정보로 따로 확인해야 합니다.

## 목적지 선택과 차량 연동

추천 기준은 현재 명시적으로 선택한 `Destination`입니다. 직접 검색하거나 순정 내비 목적지를 가져오면 이름·좌표·출처를 기기에 저장하고 재시작 시 복원합니다. 순정 내비의 이후 변경이 앱 목적지를 자동으로 바꾸지는 않습니다. 가져오기는 버튼을 누른 뒤 새로 수신한 목적지 응답을 사용하며, 목적지 없음·유효하지 않은 좌표·10초 응답 지연을 구분합니다.

기본 CTA `이곳으로 내비 안내`는 선택한 예시 정차지의 이름·좌표를 실제 `NaviHelper` 경로 API로 보냅니다. 내비 목적지가 변경될 수 있습니다. 전송 중에는 장소 변경을 막고, 완료를 확인하면 순정 내비 화면 열기를 요청합니다. SDK 연결·권한·차량 UX 제한을 검사하며, 함수 호출만으로 안내 성공을 표시하지 않습니다. 로컬 만남 체험은 `메뉴 → 앱 정보 및 설정 → 연동 점검 → 선택한 장소 만남 미리보기`에서 별도로 시작합니다. 목적지나 정차지를 새로 고르는 것만으로 이미 진행 중인 순정 내비 경로를 취소하지는 않습니다.

안내 완료 판정은 요청한 정차지 좌표가 순정 목적지와 일치하고, 경로 완료 이벤트 또는 그 일치 이후의 실제 안내 중 상태(`ROUTE_GUIDING`)가 확인됐을 때만 적용합니다. 시뮬레이션 안내 상태를 실제 안내로 처리하지 않습니다. 25초 동안 확인 응답이 없거나 연결이 끊어지면 실패로 단정하지 않고 확인 대기 상태로 표시합니다. SDK의 명시적 오류는 별도 오류 상태입니다. SDK 계약과 완료 판단은 [Pleos 연결 문서](docs/PLEOS-BRIDGE.md), 실제 기기에서 관측한 결과는 [목적지 검증 기록](verification/destinations-2026-11-14.md)에 구분합니다. 예시 정차 좌표와 조건은 실제 주행 적합성이 확인된 정보가 아닙니다.

화면 조작은 `CarUxRestrictionsManager` 정책을 따릅니다. **차량 정책이 확인되지 않거나 제한이 활성화되어 있으면 안내 미리보기를 포함한 검색·제보·경로 설정을 잠급니다.** 주행 제한 중에는 선택 장소와 거리 정보를 읽기 전용으로 유지하고 조작을 잠급니다. 상태가 불명확하면 확인 화면에서 `차량 상태 다시 확인`으로 재시도할 수 있습니다. 수동 목적지 선택도 차량 정책 잠금을 우회하지 않습니다. SDK 경로 요청도 실제 정책을 다시 검사합니다. [AOSP 차량 UX 제한 문서](https://source.android.com/docs/automotive/driver_distraction/consume)

## 핵심 체험 순서

1. Pleos 에뮬레이터를 주차 상태로 두고 앱을 엽니다. 상단의 현재 목적지를 눌러 `수영장` 등을 검색하거나 순정 내비 목적지를 가져옵니다.
2. 목적지를 고르면 주변 예시 정차지의 짧은 이름·직선 거리와 가장 가까운 추천을 지도에서 비교합니다. 상단 `바로 태우기 / 기다리기 / 주차장`을 누르면 지도 위치와 확대 수준을 유지한 채 해당 후보만 갱신하며 장소를 자동 선택하지 않습니다. 목적지 검색 옆의 상단 필터에서 방문 시간·최대 직선 거리 조건을 바꿉니다.
3. 지도 지점이나 이름표를 누르면 장소 정보와 후기가 바로 열립니다. 필요하면 메뉴의 주변 정차지·저장 목록에서도 선택할 수 있습니다. `내 상황 우선`과 전체 최신순·도움순을 비교하고 본문의 `이용 정보 보기`를 확인합니다.
4. `이곳으로 내비 안내`로 선택한 정차지를 실제 순정 내비에 요청합니다. 최종 시설 목적지와 정차지 좌표를 구분합니다. 로컬 체험만 필요하면 `메뉴 → 앱 정보 및 설정 → 연동 점검 → 선택한 장소 만남 미리보기`에서 도착 확인·후기 남기기를 진행합니다.
5. `지도 보기`로 돌아가면 일반 선택 카드를 접고 실제 지도·색상선·마커를 넓게 보여줍니다. 다른 용도를 눌러도 먼저 지도를 표시하며, 진행 중인 안내 대상은 유지합니다. `메뉴 → 저장한 곳 / 내 기록`에서 저장 지점과 제보를 관리합니다. 지원 범위 밖 목적지에서는 저장 지점 선택 전에 주변 목적지를 다시 고릅니다.
6. 공유는 기본 목적지의 기존 QR 또는 다른 목적지의 장소 정보 텍스트 복사를 사용합니다. `메뉴 → 앱 정보 및 설정 → 연동 점검`에서 차량 연결·주행 제한을 확인합니다.

경량 진단의 관측 결과는 `connected=true`, `policyKnown=true`, `drivingRestricted=false`, `destinationResponded=true`, `destinationAvailable=false`, `routeStatus=idle`, `elapsedMs=1993`입니다. 목적지가 설정되지 않아 `destinationAvailable=false`였으며, 실제 `onDestinationInfo`의 빈 목적지 응답을 정상 수신했습니다. 차량 UX 정책상 조작 제한이 해제된 상태도 확인했습니다. 이 결과는 SDK 읽기 연동의 통과 증거이며, 실제 경로 탐색 완료나 화면의 시각적 품질 검증은 포함하지 않습니다.

디버그 APK에는 AndroidX 테스트 탐색을 생략하는 `ConnectionProbeInstrumentation`이 포함됩니다. 기본 실행은 읽기 전용이며 `-e openMap true`를 명시한 경우에만 중앙 내비 화면을 요청합니다. 실제 SDK 연결, 차량 UX 정책 수신, 목적지 콜백을 읽기 전용으로 확인하며 경로를 설정하거나 바꾸지 않습니다. 일반 빌드 명령으로 디버그 APK를 만든 뒤 다음과 같이 실행합니다. `emulator-5554`는 대상 ID에 맞춰 바꾸세요.

```bash
adb -s emulator-5554 install -r app/build/outputs/apk/debug/app-debug.apk
adb -s emulator-5554 shell am instrument --user 10 -w ai.illooso.app/ai.illooso.app.ConnectionProbeInstrumentation
adb -s emulator-5554 logcat -d -s IlloosoProbe:I IlloosoPleos:I
```

내비게이션 조회 권한을 먼저 승인해야 합니다. 출력의 `success`, `connected`, `policyKnown`, `destinationResponded`, `routeStatus`와 `stream`의 `PASS`/`FAIL`을 함께 확인하세요. 목적지가 설정되지 않아 `destinationAvailable=false`인 경우에도 콜백 수신 여부는 따로 기록됩니다. 이 진단이 통과해도 시각적 QA나 실제 경로 탐색 성공을 의미하지 않습니다. 진단 클래스와 Instrumentation 선언은 `src/debug`에만 있어 릴리스 빌드에 포함되지 않습니다.

실제 지도 화면 요청 검증은 위 명령에 `-e openMap true`를 추가해 실행합니다. 이전 진단 결과는 `mapRequested=true`, `route=idle`, `elapsedMs=143`이었으며, 화면에는 현재 위치·검색 조작부만 표시되고 배경 지도는 공백이었습니다. 기본 진단과 이 옵션 모두 실제 경로를 설정하지 않습니다.

## 샘플 데이터와 공유 범위

**실제 지도와 예시 평가를 구분합니다.** 지도 배경·도로 중심선·목적지 POI는 OSM 자료입니다. 승하차·주차 후보 8개는 실제 도로 위에 배치한 예시 지점이며, 명칭에 `예시`를 표시합니다. 실제 승하차 허용 지점이나 주차장 출입구를 확인한 결과가 아닙니다. 화면의 직선 거리는 목적지와 정차지 좌표로 계산합니다. 보행 경로는 계산하지 않으며 차량 시간·우회 거리·운영 시간·정차 조건·요금·제보는 계속 예시 데이터입니다. 추천은 미확인·금지 조건을 부여한 샘플을 먼저 제외합니다. 실제 지도 또는 SDK 연결이 성공해도 예시 평가가 검증된 현장 정보로 바뀌지는 않습니다.

저장 목록은 탐색 모드·시간·거리·검색과 독립적이며, 저장된 장소 중 미확인·정차 금지 샘플과 알 수 없는 ID는 제외합니다. 저장 목록에 표시된다는 사실이 현재 이용 가능한 시간을 뜻하지는 않습니다. 지원 지역 밖의 목적지에서는 저장지점을 선택하기 전에 평거동 주변 목적지를 다시 선택하도록 안내합니다. 저장한 장소와 내 제보는 Android `SharedPreferences`에 보관합니다. 네이티브 앱과 웹의 저장소는 독립적이며, 계정·서버 동기화는 없습니다. 제보는 기기에 `확인 중`으로 저장되고 추천의 정차 허용 조건을 변경하지 않습니다. 앱 데이터 삭제 또는 제거 시 로컬 기록이 사라집니다.

QR은 `MainActivity.COMPANION`에 지정된 [배포된 동승자 웹](https://illooso-pyeonggeo-prototype.yangseungsang.chatgpt.site)에 장소 정보를 담은 **2시간 유효 스냅샷**을 연결합니다. 현재 공유 웹은 소유자 검토용 비공개 호스팅이므로 계정 로그인과 접근 권한에 따라 다른 동승자가 열지 못할 수 있습니다. QR 발급 자체가 외부 공개를 의미하지 않습니다. 공개 승객 서비스를 운영하려면 접근 정책이 정해진 웹 주소로 교체해야 합니다.

기존 QR 공유는 평거동 기본 목적지(`d1`)에 한정됩니다. 다른 목적지에서는 목적지명·만날 곳·직선 거리·정차지 좌표·OSM 링크를 텍스트로 복사합니다. 실시간 차량 추적, 다른 기기로의 변경 반영, 서버 기반 취소 기능은 없습니다. 수정한 정보는 새 링크로 전달해야 합니다. 공유 URL은 암호화된 비밀 토큰이 아니므로 민감한 정보를 담는 용도로 사용할 수 없습니다.
