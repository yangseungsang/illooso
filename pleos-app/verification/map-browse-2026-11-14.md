# 지도 우선 탐색 검증 · 1.10.0-map-browse

## 변경

- 첫 실행과 목적지 변경 시 첫 후보를 자동 선택하지 않는다. 주변 후보를 지도에 먼저 표시한다.
- 바로 태우기·기다리기·주차장을 상단의 세 버튼으로 바로 선택한다. 선택 색상과 접근성 상태를 제공하며, 용도를 바꾸면 후기 카드를 닫고 해당 후보를 모두 볼 수 있게 지도를 맞춘다.
- 지도 지점을 누르면 장소 정보·요약·후기를 바로 연다. 별도의 상세 버튼은 없다.
- 지도 보기로 복귀하면 일반 선택을 해제하고 작은 안내와 후보 수만 남긴다. 방문 시간·직선 거리 필터도 이 안내에서 열 수 있다.
- 목록 검색 변경 시 지도 후보와 하단 후보 수를 함께 갱신한다. 빈 결과에서 임의의 장소를 대신 선택하지 않는다.
- 진행 중인 안내 대상은 용도 변경으로 버리지 않는다. 순정 안내가 idle로 끝나면 지도 탐색 중 보존했던 선택을 해제한다. 사용자가 직접 열어 둔 후기와 오류·확인 대기 상태는 유지한다.
- 실제 OSM 지도, 도로 평가 예시, 후기 카드 디자인, 내비 요청 기능을 유지한다.

## Pleos 화면 확인

Pleos 2.1.0 AVD `emulator-5554`, user 10, 주차 상태, 중앙 앱 패널 약 840px에서 확인했다. 목적지는 기존에 저장된 신세계수영장이며, 기본 최대 직선 거리는 500m다. 후보 수는 확인 당시 도착 시간 기준이다.

1. 앱 설치 후 실행: 자동 후기 카드 없이 실제 지도와 바로 태우기 후보 4곳 표시.
2. 기다리기 선택: 2곳만 표시되고 상세가 자동으로 열리지 않음.
3. 주차장 선택: 2곳의 P 마커와 선택된 버튼 색상 표시.
4. P 마커 선택: 신평공원길39번길 예시 주차 공간(p2)의 후기 36건, 차량 4분·직선 281m, 장점·주의 요약과 본문 표시.
5. 최종 APK에서 바로 태우기 승하차 마커(p1) 선택: 평거로36번길 예시 승하차 지점의 후기 18건, 차량 3분·직선 235m 표시.
6. 해당 후기에서 주차장 버튼 선택: 이전 승하차 카드가 사라지고 주차 후보 2곳 지도 복원.
7. 최종 APK에서 p2를 다시 열고 지도 보기 선택: 후기와 큰 장소 카드가 닫히고 두 후보·작은 안내만 표시. 선택 강조도 해제됨.
