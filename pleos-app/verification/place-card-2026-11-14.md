# 장소 카드 통합 · 2026-11-14

대상: Pleos 네이티브 `1.5.0-place-card`, versionCode 6. Pleos 2.1.0 AVD `emulator-5554`, 사용자 10, 약 841 × 1210dp 앱 영역.

## 변경

- 별도 `상세` 버튼을 제거했다. 초기 추천과 지도·목록에서 선택한 장소는 후기까지 포함한 카드로 바로 열린다.
- 카드는 앱 영역의 좌우 24dp 여백을 제외한 전체 너비를 사용한다. 좁은 지도 옆 패널과 하단 요약을 하나로 통합했다.
- 장소명·차량 이동 시간·도보 거리·방문 후기/이용 정보 탭은 카드 상단에, 결정 버튼과 공유는 하단에 고정한다. 가운데 본문만 ScrollView를 사용한다.
- 넓은 화면에서는 후기의 좋았던 점과 살펴볼 점을 나란히 배치한다. 글자 배율을 고려해 공간이 부족하면 세로로 표시한다.
- 전문이 이미 보이는 후기에는 `더 읽기`를 표시하지 않는다. 실제 말줄임이 발생한 경우에만 펼치기를 제공한다.
- `지도 보기`로 카드를 접으면 지도와 간단한 장소 요약이 나타난다. 지도 지점 또는 접힌 카드의 장소명을 누르면 후기부터 다시 열린다.
- 접힘 상태를 별도로 관리해 화면 갱신만으로 다시 열리지 않게 했다. 같은 장소를 다시 열어도 안내 상태를 초기화하지 않는다. 다른 장소를 선택한 경우에만 기존 정책대로 안내 미리보기를 초기화한다.
- 후기 집계·정렬·표본 기준·기기 내 기록의 의미는 [이전 후기 검증](reviews-2026-11-14.md)과 같다. 차량 정책 제한도 유지한다.

## 확인한 결과

- 최종 APK 설치·실행 후 기본 추천의 통합 카드가 자동으로 열리고, 요약과 첫 후기 전문 및 출처·도움 수가 한 화면에 표시됨을 확인했다.
- `상세` 버튼이 사라지고 카드 너비가 확장된 것을 확인했다.
- `이용 정보` 전환 시 진입 방향·이용 시간·요금이 같은 카드에 표시됐다.
- `지도 보기`로 접으면 지도와 간단한 요약이 복구됐다.
- 다른 지도 지점 선택 시 새 장소명·거리·후기 요약을 가진 카드가 별도 상세 조작 없이 열렸다.
- 최종 빌드에서 전문이 보이는 첫 후기의 불필요한 `더 읽기` 버튼이 제거된 것을 확인했다.
- 사용자가 앱을 조작하기 시작한 뒤 추가 UI 조작을 중단했다. 최종 관측에서는 안내 미리보기 지도와 `도착 확인`이 표시됐다.

JDK 17로 `:app:assembleDebug :app:testDebugUnitTest`가 성공했다. 기존 도메인 테스트 27개(장소 15, 선택 4, 후기 8)가 실패·오류 없이 통과했다. 이번 레이아웃 변경을 그대로 반복하는 단위 테스트는 추가하지 않았다.

전달 파일: [APK](../artifacts/illooso-pleos-debug.apk), [SHA-256](apk-sha256.txt).

## 검증 범위

이번 수동 점검은 위 AVD 크기에 한정한다. 짧은 높이의 창·큰 글자 배율·주행 정책 전환·후기 CRUD 전체 흐름을 새로 검증하지 않았다. 특히 매우 짧은 창에서는 고정 헤더와 하단 버튼 때문에 본문 공간이 부족할 수 있어 추가 반응형 조정이 필요하다. 후기의 긴 목록 스크롤은 기존 본문 구조를 유지했지만 이번 통합 카드에서는 끝까지 재검증하지 않았다.

실차 적합성, 실제 SDK 경로 성공, 순정 지도 배경 공백 복구를 확인한 결과가 아니다. 지도·도로·후기는 계속 예시 데이터이며 외부 서비스로 후기나 위치를 전송하지 않는다.
